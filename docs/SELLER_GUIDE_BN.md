## ৪. লাইসেন্স তৈরি (নিজের ফোনের Termux/কম্পিউটারে)
```
python license_server/issue_license.py --private-key-file ~/secrets/license_private.key \
  --customer-ref "order-1042" --license-type commercial --perpetual \
  --out ~/licenses/order-1042.license.json --also-base64 --register-file ~/licenses/register.jsonl
```
- চিরস্থায়ীর বদলে মেয়াদি হলে `--perpetual` বাদ দিয়ে `--expires 2027-12-31`। `trial` লাইসেন্সে `--expires` বাধ্যতামূলক।
- টুল সারাংশ দেখিয়ে license ID টাইপ করতে বলবে। private key ফাইল `chmod 600` ও প্রজেক্টের বাইরে থাকতে হবে, না হলে টুল চলবে না।
- `register.jsonl`-এ শুধু অ-গোপন তথ্য জমে (ID, রেফারেন্স, ধরন, তারিখ)। এটার ব্যাকআপ রাখুন।
- **যাচাই:** টুল নিজেই ফাইলটি পাবলিক কী দিয়ে যাচাই করে তবেই লেখে। আপনি চাইলে একটি পরীক্ষা-ইনস্টলেশনে ফাইলটি বসিয়ে License পেজে "Active" দেখুন।
