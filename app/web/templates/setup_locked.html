Setup is locked

This installation runs in production mode and has no valid SETUP_TOKEN, so nobody can create the administrator account yet. This protects a fresh installation from being claimed by a stranger.

The owner of this installation must:

  1. Run python scripts/generate_keys.py (or invent a long random value of at least 16 characters).
  2. Put it into .env (or the hosting dashboard) as SETUP_TOKEN=... and restart the web service.
  3. Open this page again and enter the same token together with the administrator details.

After the administrator exists, this page disappears and the token is no longer needed.
